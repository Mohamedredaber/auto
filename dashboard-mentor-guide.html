Hint — Champs de la migration
HINT ▶
// Migration cars Schema::create('cars', function (Blueprint $table) { $table->id(); $table->foreignId('agency_id')->constrained()->cascadeOnDelete(); $table->string('brand'); // BMW, Porsche... $table->string('model'); // Série 5, 911... $table->string('city'); $table->decimal('price_per_day', 8, 2); $table->enum('status', ['available', 'rented', 'maintenance']) ->default('available'); $table->string('image')->nullable(); $table->integer('year')->nullable(); $table->string('fuel_type')->nullable(); // essence, diesel, électrique $table->string('transmission')->nullable(); // manuelle, automatique $table->integer('seats')->nullable(); $table->text('description')->nullable(); $table->timestamps(); });

Exercice — Écrire cars.js
EXERCICE ▶

Crée src/api/cars.js avec les fonctions suivantes :

  • getCars(params) — avec filtres et pagination en query params
  • getCar(id) — une seule voiture
  • createCar(formData) — multipart/form-data (image !)

Exercice — Filtres côté Laravel
EXERCICE ▶

Dans CarService::getAgencyCars(), gère les filtres :

  • ?search=BMW → filtre sur brand ou model
  • ?status=available → filtre sur le statut
  • ?city=Casablanca → filtre sur la ville
  • ?page=2 → pagination Laravel
💡 Utilise les query scopes Eloquent ou simplement des when() conditionnels sur la query builder.
💡
Hint — Filtres avec when() + debounce
HINT ▶
// CarService.php public function getAgencyCars(int $agencyId, array $filters = []): LengthAwarePaginator { return Car::where('agency_id', $agencyId) ->when($filters['search'] ?? null, function ($q, $search) { $q->where('brand', 'like', "%{$search}%") ->orWhere('model', 'like', "%{$search}%"); }) ->when($filters['status'] ?? null, fn($q, $s) => $q->where('status', $s)) ->when($filters['city'] ?? null, fn($q, $c) => $q->where('city', $c)) ->paginate(10); } // React — debounce pour la recherche // npm install use-debounce import { useDebouncedCallback } from 'use-debounce' const handleSearch = useDebouncedCallback((value) => { dispatch(setFilters({ search: value })) dispatch(fetchCarsThunk()) }, 400) // ← attendre 400ms après la dernière frappe

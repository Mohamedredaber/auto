AutoConnect

Plateforme web de location de voitures

Document de présentation

1. Contexte et présentation du projet

Entreprise : AutoConnect

Problème : Difficulté pour les clients de trouver rapidement une voiture disponible. Manque de visibilité pour les petites agences locales.

Solution : Plateforme web centralisant les offres de location, permettant de comparer et réserver facilement.

Objectifs :

  • Mettre en relation clients et agences
  • Réservation via formulaire ou redirection
  • Interface admin pour suivi agences, véhicules, clics, commissions
  • Revenu via commissions (simple ou intégrée)

2. Acteurs du système

👥 Clients

Personnes cherchant une voiture à louer

  • Rechercher un véhicule
  • Voir les détails
  • Faire une réservation
  • Ajouter aux favoris
  • Ajouter un commentaire
  • Contacter une agence

🏢 Admin Agences

Gère la plateforme et supervise les agences

  • Créer/gérer comptes employés
  • Créer/modifier/supprimer agences
  • Suivre réservations, stats, revenus

🔧 Employé Agences

Gère les véhicules et réservations de son agence

  • Ajouter/modifier/supprimer véhicules
  • Gérer les annonces
  • Traiter les demandes
  • Mettre à jour infos agence

⚙️ Administrateur

Gestionnaire du site

  • Valider les agences
  • Supprimer annonces frauduleuses
  • Suivre réservations
  • Voir stats et commissions

3. Description graphique (UI/UX)

🏠 Page d’accueil

En-tête : Logo, menu (Accueil, S'inscrire, Contact, À propos), barre de recherche avec filtres (ville, type, marque, carburant, prix) et bouton Rechercher.

Liste des voitures : Affichage en cards (image, nom/modèle, marque, carburant, prix/jour, like, commentaire, favoris, boutons Voir plus / Réserver).

📋 Dashboard Agence

Header (logo, profil, déconnexion), menu (tableau de bord, véhicules, réservations, statistiques), cartes statistiques, actions rapides.

📊 Interface Administrateur

Header, menu latéral, tableau de bord avec cartes (agences, véhicules, réservations, clics, revenu), graphiques, actions rapides.

5. Modèle économique

💰 Commission sur réservation

La plateforme prélève une commission sur chaque réservation.

Exemple : location à 300 DH / jour, commission 10 % → AutoConnect gagne 30 DH par jour.

Modèle simple et attractif pour toutes les parties.
